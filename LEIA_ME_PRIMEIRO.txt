🚀 COMO COMEÇAR (5 PASSOS RÁPIDOS):

1️⃣  INSTALAR TUDO DE UMA VEZ
    Execute no terminal:
    ./setup.sh

2️⃣  CONFIGURAR BANCO DE DADOS POSTGRESQL
    createdb enem_analise
    cd backend && npm run migrate && cd ..

3️⃣  INICIAR O BACKEND
    ./start-backend.sh
    (Vai rodar em http://localhost:3000)

4️⃣  CONFIGURAR IP NO MOBILE
    Abra: mobile/src/services/api.js
    Mude: API_BASE_URL para o IP da sua máquina

    Exemplos:
    - Android Emulator: http://10.0.2.2:3000/api
    - Seu celular: http://192.168.X.X:3000/api
    - iOS Simulator: http://localhost:3000/api

5️⃣  INICIAR O APP MOBILE
    ./start-mobile.sh
    (Escaneie o QR code com o app Expo Go)

🔧 PROBLEMAS COMUNS E SOLUÇÕES:

❌ "Erro de conexão com a API"
✅ Verifique se o backend está rodando (./start-backend.sh)
✅ Confira se o IP está correto em mobile/src/services/api.js
✅ Certifique-se que celular e computador estão na mesma rede

❌ "Erro no banco de dados"
✅ Verifique se o PostgreSQL está rodando
✅ Confira as credenciais no arquivo backend/.env
✅ Execute: cd backend && npm run migrate

❌ "Expo não funciona"
✅ Limpe o cache: expo start -c
✅ Reinstale: rm -rf node_modules && npm install
